# Đức Mạnh – Gia sư Toán

## Các file cần upload

- `index.html`
- `style.css`
- `script.js`
- `Duc-Manh-Gia-Su.vcf`
- thư mục `assets`

Trong `assets`:
- `avatar.jpg` – ảnh đại diện hiện có của bạn
- `graduation.jpg` – ảnh tốt nghiệp Thạc sĩ
- `parent-1.jpg` đến `parent-4.jpg` – 3–4 ảnh tin nhắn phụ huynh/học sinh

**Lưu ý:** Tôi không tạo giả ảnh tốt nghiệp hoặc tin nhắn phụ huynh. Hãy thay bằng ảnh thật của bạn.

GitHub Pages: chọn branch `main`, folder `/root`.
